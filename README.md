# 🎃 Pumpkin Sentinel

**A DIY Halloween pumpkin with a spooky personality!**

Pumpkin Sentinel is a low-cost, open-source Halloween decoration built with an ESP32, motion detection, creepy sounds and glowing lights.

The goal is to build something fun from simple materials instead of buying an expensive, ready-made decoration.

## ✨ Planned Features

- 👻 Motion-activated Halloween effects
- 🔊 Spooky laughs and screams
- 💡 Glowing pumpkin eyes and mouth
- 🌫️ Optional fog effect
- 🌐 Project website and build documentation
- 📊 Public activation counter (planned)

## 🧰 Hardware

- ESP32 development board
- Plastic Halloween pumpkin bucket
- PIR motion sensor
- DFPlayer Mini MP3 module
- microSD card
- Small speaker
- LEDs and suitable resistors
- Breadboard and jumper wires

Some features are still under development. The hardware list and wiring diagrams will be updated as the project progresses.

## 🛠️ Build Progress

This project is being built step by step, with a focus on low cost, simple assembly and beginner-friendly instructions.

Real photos, wiring diagrams, source code and lessons learned will be added during development.
