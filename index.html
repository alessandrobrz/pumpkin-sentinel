Meet Pumpkin Sentinel

A spooky personality, a tiny budget and a little DIY magic. Building a homemade Halloween pumpkin with ESP32, creepy sounds, glowing lights and motion detection.

Follow the build View on GitHub

👻 The plan

🚶

Motion detection

Wake up the pumpkin when someone approaches.

🔊

Spooky sounds

Play creepy laughs, screams and Halloween sounds.

💡

Glowing face

Illuminate the eyes and mouth from inside the pumpkin.

🌫️

Fog effect

An optional mist effect is planned for a future version.

🧰 Planned hardware

  • ESP32 development board
  • Low-cost plastic Halloween bucket
  • PIR motion sensor
  • DFPlayer Mini and microSD card
  • Small speaker
  • LEDs, resistors and jumper wires
  • Breadboard for prototyping

This is a provisional list. Components and wiring will be confirmed and documented as the prototype develops.

🛠️ Build progress

Phase 1 — Physical prototype

The project starts with an inexpensive orange Halloween bucket and a witch hat. Next steps include preparing the pumpkin face, testing the lighting and adding the electronics.

Real photos, wiring diagrams and code will be published as the build progresses.

Planned features are not yet confirmed as working.
